# LESK Sites — União Verde Azul FC

Demonstração comercial **inteiramente fictícia** para clubes de futebol amador. Não representa um clube real.

## Páginas
- index.html — início e escudo
- historia.html — fundação, cronologia e diretoria
- conquistas.html — oito títulos e campanha de 2024
- clube.html — elenco, ídolos, galeria demonstrativa, notícias e patrocinadores

## Execução
Abra `index.html` no navegador ou execute um servidor HTTP estático apontando para esta pasta. Não há dependências, banco de dados, login ou serviço pago.

## Validação
Execute `node tests/check.mjs` na raiz desta pasta. Inspecione também visualmente em desktop e celular. Fotos e vídeos são placeholders intencionais, não links quebrados.

## Limites
Não fazer deploy ou merge sem aprovação. Não substituir imagens fictícias por fotografias de terceiros sem licença. O painel administrativo está fora da demonstração.
