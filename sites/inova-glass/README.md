# INOVA GLASS — MVP institucional

Site estático isolado em `sites/inova-glass/` dentro de `DevLESK/lesk-tecnologia`.

## Uso local
Abra `index.html` no navegador ou sirva esta pasta com um servidor HTTP estático. Não requer instalação, banco de dados, build nem backend.

## Escopo
HTML/CSS/JS puro, navegação responsiva, serviços, áreas de interesse comercial, portfólio reservado para material real e contatos oficiais configuráveis.

## Pendências de homologação
- Confirmar WhatsApp e Instagram e preencher o objeto `contacts` em `assets/js/main.js`.
- Receber fotos e vídeos autorizados para substituir os cartões de portfólio.
- Validar o texto institucional, a logomarca oficial e a cobertura real das regiões.
- Conferir fidelidade aos mockups aprovados (não anexados ao repositório).
- Validar visualmente em dispositivos reais e com ferramentas de acessibilidade.
- Conferir as configurações de deploy antes de qualquer publicação.

## Restrições
Não apresentar endereço residencial como loja; não afirmar atendimento em localidade sem confirmação; não criar avaliações ou portfólio fictícios; não publicar sem autorização.

## Isolamento
Todos os arquivos deste MVP estão dentro de `sites/inova-glass/`. Nenhum arquivo preexistente precisa ser alterado.
